## SCRIPT CUSTOMIZATION NOTES

### For Different Audiences

**Individual Fishermen**
- Emphasize: Simplicity, immediate ROI, fuel savings
- Show: Single-vessel dashboard, easy-to-use interface
- Tone: Practical, straightforward, respectful of experience

**Fleet Operators**
- Emphasize: Multi-vessel management, aggregate savings, reporting
- Show: Fleet dashboard, role-based access, API integration
- Tone: Professional, data-driven, efficiency-focused

**Government/Research**
- Emphasize: Data accuracy, methodology, regulatory compliance
- Show: Data sources, validation metrics, research applications
- Tone: Technical, credible, collaborative

### Regional Customization
- Swap Bristol Bay example for relevant region
- Use appropriate species (salmon, halibut, cod, crab)
- Reference local harbors and fishing communities
- Adjust seasonal timing references
