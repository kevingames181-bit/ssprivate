# SeaScope Alaska - Business Card Design Specifications

## Card Dimensions
- **Standard Size**: 3.5" x 2" (89mm x 51mm)
- **Bleed**: 0.125" (3mm) on all sides
- **Safe Zone**: 0.25" (6mm) from edges
- **Orientation**: Horizontal
- **Finish**: Matte or glossy (matte recommended for professional feel)
- **Paper Stock**: 16pt cardstock minimum

---

## FRONT SIDE DESIGN

### Layout
```
┌─────────────────────────────────────────────┐
│                                             │
│  [SEASCOPE LOGO]                           │
│  SeaScope Alaska                           │
│                                             │
│  Predictive Profit Optimization            │
│                                             │
│                                             │
│  [YOUR NAME]                               │
│  Founder                                    │
│                                             │
└─────────────────────────────────────────────┘
```

### Design Elements

**Logo Placement**
- Position: Top left, 0.5" from top, 0.5" from left
- Size: 0.75" x 0.75" (or proportional)
- Style: SeaScope wave/fish icon + text logo

**Company Name**
- Font: Montserrat Bold or similar modern sans-serif
- Size: 18pt
- Color: Navy blue (#1e3c72)
- Position: Next to logo, vertically centered

**Tagline**
- Text: "Predictive Profit Optimization"
- Font: Montserrat Regular
- Size: 10pt
- Color: Medium gray (#666666)
- Position: Below company name

**Your Name**
- Font: Montserrat SemiBold
- Size: 14pt
- Color: Navy blue (#1e3c72)
- Position: Bottom left, 0.5" from bottom

**Title**
- Text: "Founder"
- Font: Montserrat Regular
- Size: 10pt
- Color: Medium gray (#666666)
- Position: Below your name

**Background**
- Color: White or very light blue (#f8f9fa)
- Optional: Subtle wave pattern or Alaska coastline silhouette in background (very faint)

### Design Elements

**Contact Information**
- Font: Montserrat Regular
- Size: 11pt
- Color: Navy blue (#1e3c72)
- Icons: Simple line icons in brand color
- Spacing: 0.2" between each line
- Position: Top half of card, left-aligned with 0.5" margin

**QR Code**
- Size: 1" x 1"
- Position: Center-right, middle of card
- Links to: Demo scheduling page (Calendly or website)
- Label: "Schedule Demo" below QR code (8pt, gray)
- Include error correction level H (high) for durability

**Tagline**
- Text: "Know exactly when and where to fish for maximum return"
- Font: Montserrat Italic
- Size: 9pt
- Color: Medium gray (#666666)
- Position: Bottom of card, centered
- Style: Quotation marks for emphasis

**Background**
- Color: White or very light blue (#f8f9fa)
- Optional: Subtle Alaska map outline in background (very faint)

## PRINTING SPECIFICATIONS

### File Format
- **Design File**: Adobe Illustrator (.ai) or PDF
- **Print File**: PDF with embedded fonts and images
- **Color Mode**: CMYK (not RGB)
- **Resolution**: 300 DPI minimum

### Print Quantity Recommendations
- **Initial Order**: 250-500 cards
- **Cost**: $20-$50 for 250 cards (online printers)
- **Turnaround**: 3-5 business days

### Recommended Printers
- **Online**: Vistaprint, Moo, GotPrint, PrintPlace
- **Local**: Alaska print shops for faster turnaround
- **Premium**: Moo (high quality, unique finishes)

### Print Options
- **Finish**: Matte (recommended) or glossy
- **Paper**: 16pt cardstock minimum, 18pt preferred
- **Coating**: UV coating on front only (optional)
- **Special**: Rounded corners (optional, modern look)

## QR CODE SETUP

### QR Code Generator
- Use: QR Code Generator (qr-code-generator.com) or similar
- Type: URL
- Destination: https://seascope-alaska.com/demo or Calendly link
- Error Correction: Level H (30% - highest)
- Format: SVG or high-res PNG (300 DPI)

### QR Code Best Practices
- Test on multiple devices before printing
- Ensure sufficient contrast (dark on light)
- Leave white space around QR code (quiet zone)
- Include text label ("Schedule Demo")
- Update destination URL if needed (use redirect)

## USAGE GUIDELINES

### When to Give Out Cards
- After demos and presentations
- At industry events and conferences
- During customer discovery interviews
- Networking at harbors and marine businesses
- Follow-up meetings with prospects

### How to Present
- Keep cards clean and undamaged
- Hand out with both hands (professional)
- Mention the QR code for easy demo scheduling

### Quantity Planning
- **Events**: 50-100 cards per event
- **Daily Carry**: 10-20 cards
- **Reorder Trigger**: When down to 50 cards
